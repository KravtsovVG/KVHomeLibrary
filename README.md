# KVHomeLibrary

Домашняя библиотека книг **FB2** с веб-сервером и каталогом **OPDS 1.2**.

Программа рекурсивно читает `.fb2` и `.fb2.zip`, извлекает метаданные книги,
складывает их в SQLite и отдаёт каталог, разделённый по **авторам**,
**категориям (жанрам)** и **сериям**. Каталог открывается в OPDS-читалках
(KOReader, Librera, Moon+ Reader, Calibre и др.).

## Возможности

- Рекурсивный обход папки с книгами (подпапки, `.fb2`, `.fb2.zip`).
- Разбор FB2: название, авторы, аннотация, жанры, серия и номер в серии,
  издательство, город, год, ISBN, язык, язык оригинала, переводчики,
  ключевые слова, идентификатор и версия документа, дата, обложка.
- Русские названия категорий и синонимы. Варианты кодов `sf-action`,
  `sf_action` и «Боевая фантастика» объединяются в одну категорию;
  неизвестные английские коды получают русское название.
- Поддержка разных кодировок (UTF-8, Windows-1251, KOI8-R и др.) и
  пространств имён FB2.
- SQLite-база с нормализованной схемой: `books`, `authors`, `genres`,
  `series`, `opds_sources`, связи `book_authors` и `book_genres`.
- Полнотекстовый поиск FTS5 по названию, аннотации, ключевым словам,
  авторам и серии (с автоматическим откатом на `LIKE`).
- OPDS-каталог:
  - `/opds` — корень;
  - `/opds/authors` — авторы;
  - `/opds/genres` — категории;
  - `/opds/series` — серии;
  - `/opds/books` — все книги;
  - `/opds/search?q=...` — поиск;
  - `/opds/opensearch.xml` — OpenSearch-описание;
  - `/download/{id}` — файл книги;
  - `/covers/{id}` — обложка.
- Веб-каталог в браузере: поиск, фильтры, разделы по авторам,
  категориям и сериям, карточки книг и скачивание.
- Вся HTML-разметка вынесена в `kvhomelibrary/templates`, стили и AJAX-код —
  в `kvhomelibrary/static`; Python-модули только готовят данные.
- Встроенная читалка FB2 с тремя режимами:
  - обычная вертикальная прокрутка;
  - одна страница на экран с листанием;
  - две страницы на широком экране с листанием.
  Текст на страницы раскладывается CSS-колонками, позиция чтения
  сохраняется в браузере.
- Читалка EPUB на epub.js: страницы/прокрутка, оглавление, темы,
  размер шрифта и сохранение позиции по CFI.
- В карточке книги есть ссылка «все книги серии» — для локального каталога
  и для внешних OPDS-источников (через поиск источника).
- Внешние OPDS-источники: хранение в SQLite, просмотр чужих каталогов
  прямо в браузере и скачивание FB2 в свою библиотеку.
- HTML-описания книг из внешних OPDS отображаются с форматированием;
  опасные теги, скрипты и обработчики событий вырезаются.
- В карточках внешних OPDS показываются обложки и ссылки `related`
  («Все книги автора», «Все книги серии» и т. п.).
- Администрирование в браузере: редактирование метаданных, удаление
  записей из каталога, сканирование библиотеки и перестроение индекса.
- Импорт из ZIP/7Z/RAR: выбор каталога, фильтр по дате создания архива и
  типам FB2/PDF/DjVu/EPUB; книги добавляются и обновляются, а файлы
  сохраняются в ZIP-хранилище библиотеки.
- Скачивание книг из внешних OPDS через AJAX: кнопка показывает прогресс,
  ошибки выводятся уведомлением и непосредственно под кнопкой, страница
  не перезагружается.
- Редактирование книги открывается во всплывающем окне; есть кнопки
  «Сохранить» и «Сохранить и закрыть».
- Пагинация фидов, корректные `self`/`start`/`up`/`next`/`previous`/`first`/`last`.
- Обложки сохраняются в `covers/` и отдаются с ETag и кэшированием.
- Повторное сканирование не дублирует книги: дедупликация по SHA-256,
  перенос файла обновляет путь, а не создаёт новую запись.
- Ошибки разбора не ломают импорт: книга сохраняется с текстом ошибки и
  исключается из каталога, но видна в статистике.

## Требования

- Python 3.10 или новее.
- Сторонних зависимостей нет — только стандартная библиотека
  (`sqlite3`, `xml.etree`, `http.server`).
- Для импорта 7Z/RAR: 7-Zip (`7z`) или `unrar`. ZIP читается встроенно.

## Быстрый старт

```bat
cd G:\Projects\KVHomeLibrary

python -m kvhomelibrary init --db data\library.db
python -m kvhomelibrary scan "D:\Books" --db data\library.db
python -m kvhomelibrary serve --db data\library.db --library "D:\Books" --scan --host 0.0.0.0
```

Открыть в браузере: <http://127.0.0.1:8080/>.
Адрес каталога для OPDS-читалки: `http://127.0.0.1:8080/opds`.
Администрирование: <http://127.0.0.1:8080/admin> (по умолчанию только
с этого компьютера).
Для доступа с телефона используйте IP компьютера, который сервер печатает
при старте (см. раздел ниже).

На Windows можно просто перетащить папку с книгами на `run.bat`:

```bat
run.bat "D:\Books"
```

`run.bat` создаст `data\library.db`, просканирует папку и запустит сервер.
Для повторного сканирования без запуска сервера используйте `scan.bat`.

### Веб-каталог и администрирование

После запуска откройте <http://127.0.0.1:8080/>. В браузере доступны:

| Адрес | Назначение |
| --- | --- |
| `/` | главная страница с поиском и последними книгами |
| `/ui/books` | все книги, поиск и фильтры |
| `/ui/authors` | авторы |
| `/ui/genres` | категории (жанры) |
| `/ui/series` | серии |
| `/ui/books/{id}` | карточка книги |
| `/read/{id}` | встроенная читалка книги |
| `/admin` | администрирование |
| `/admin/books` | управление книгами |
| `/admin/books/{id}` | редактирование метаданных |
| `/admin/sources` | внешние OPDS-источники |
| `/admin/sources/{id}` | настройка источника |

В администрировании можно:

- сканировать библиотеку из браузера;
- импортировать книги из ZIP/7Z/RAR с фильтрами по дате архива и типам
  FB2/PDF/DjVu/EPUB;
- перестраивать поисковый индекс;
- редактировать название, аннотацию, авторов, категории, серию, номер,
  язык, год, издательство, город и ISBN во всплывающем окне;
- сохранять изменения кнопкой «Сохранить» или «Сохранить и закрыть»;
- удалять книгу из каталога (FB2-файл на диске остаётся);
- видеть ошибки разбора;
- подключать внешние OPDS-каталоги и скачивать из них книги.

Правки сохраняются в SQLite. Неизменённые FB2-файлы при сканировании
пропускаются, поэтому ручные правки сохраняются. Если файл изменится,
его метаданные будут прочитаны заново и заменят изменения.

### Внешние источники OPDS

Откройте `/admin/sources`, нажмите «Добавить источник» и укажите:

- название;
- адрес OPDS-каталога, например `https://example.org/opds`;
- логин и пароль, если источник их требует.

После сохранения нажмите «Открыть каталог»: навигационные разделы
и книги отобразятся прямо в браузере. У книги будет кнопка
**«Скачать в каталог»**. Скачивание идёт через AJAX: страница не
перезагружается, при ошибке сообщение показывается и в уведомлении,
и под кнопкой, после успеха появляется ссылка «Открыть книгу».
Поддерживаются книги в формате FB2 (`application/fb2+xml` и
`application/fb2+zip`).

Поддерживаются как стандартные навигационные ссылки OPDS
(`rel="subsection"`), так и варианты вроде `http://opds-spec.org/sort/new`,
которые использует Flibusta. Описания в `content type="html"` и
`content type="xhtml"` показываются как HTML: абзацы, списки, ссылки и
картинки. Скрипты, стили, iframe и `javascript:` удаляются.

Если у книги указана серия, в карточке появляется ссылка
**«все книги серии»**. В локальном каталоге она открывает фильтр по серии,
во внешнем OPDS — поиск источника по названию серии (если источник
поддерживает OPDS-поиск).

Во внешних карточках также показываются:

- обложка из `http://opds-spec.org/image` — относительный адрес
  разрешается относительно URL OPDS-фида; клик открывает страницу книги
  на внешнем сайте;
- ссылки `rel="related"` с заголовками вроде «Все книги автора» —
  по ним можно перейти в соответствующий раздел внешнего каталога.

Скачанный файл сохраняется в подкаталог `OPDS` внутри каталога книг
(например, `D:\Books\OPDS`), после чего автоматически разбирается
и добавляется в библиотеку. Каталог книг должен быть доступен серверу
на запись.

Логин и пароль источника хранятся в локальной SQLite. Используйте
отдельный пароль для OPDS, а не основной пароль от аккаунта.
Управление источниками доступно только в разделе `/admin`.

По умолчанию `/admin` доступен **только с компьютера, где запущен сервер**.
Для администрирования с телефона или другого ПК задайте пароль:

```bat
set KVL_ADMIN_PASSWORD=мой-пароль
run.bat "D:\Books"
```

или при ручном запуске:

```bat
python -m kvhomelibrary serve --db data\library.db --admin-password "мой-пароль"
```

После этого браузер запросит логин и пароль. Логин может быть любым,
проверяется только пароль. Пароль передаётся по HTTP, поэтому используйте
его только в доверенной локальной сети; для выхода в интернет ставьте
сервер за HTTPS-прокси.

Подробная инструкция с systemd, правами, ufw и автоматическим сканированием:

### Доступ с телефона или другого компьютера

`run.bat` запускает сервер на всех интерфейсах (`--host 0.0.0.0`). При старте
программа печатает реальные адреса, например:

```text
Локально:  http://127.0.0.1:8080/opds
В сети:    http://192.168.1.101:8080/opds
```

Для другого устройства используйте **свой** адрес из строки «В сети»,
а не пример из документации. Узнать IPv4 можно командой:

```bat
ipconfig
```

Нужен адрес адаптера Wi-Fi или Ethernet, у которого указан «Основной шлюз»
(например, `192.168.1.101`).

Если страница всё равно не открывается:

1. Проверьте, что сервер запущен и в его окне нет ошибки.
2. Откройте `http://<IP>:8080/` на самом компьютере — так проверяется,
   что сервер слушает нужный адрес.
3. Разрешите Python в брандмауэре Windows. Проще всего один раз запустить
   `allow-firewall.bat` **от имени администратора** — он добавит входящее
   правило для TCP-порта 8080.
4. Убедитесь, что телефон и компьютер подключены к одной сети Wi-Fi.
   Гостевые сети и изоляция клиентов на роутере могут блокировать доступ.
5. Если сеть Windows определена как «Общественная», переключите её на
   «Частная»: параметры сети → свойства подключения.

В OPDS-читалке указывайте адрес с путём `/opds`:

```text
http://192.168.1.101:8080/opds
```

Корень `http://192.168.1.101:8080/` тоже понимает OPDS-клиенты: сервер
отдаёт им XML-каталог, а браузеру — обычную страницу.

В комплекте есть три небольшие книги в `examples\books`:

```bat
python -m kvhomelibrary scan examples\books --db data\demo.db
python -m kvhomelibrary serve --db data\demo.db
```

## Команды

| Команда | Назначение |
| --- | --- |
| `python -m kvhomelibrary init` | создать базу и каталог обложек |
| `python -m kvhomelibrary scan PATH` | просканировать папку и обновить базу |
| `python -m kvhomelibrary serve` | запустить OPDS-сервер |
| `python -m kvhomelibrary stats` | показать статистику и ошибки разбора |
| `python -m kvhomelibrary reindex` | перестроить поисковый индекс FTS5 |

Полезные параметры:

```text
--db PATH             путь к базе (по умолчанию library.db)
--covers PATH         каталог обложек (по умолчанию рядом с базой)
scan --no-recursive   не заходить в подпапки
scan --prune          удалить записи о пропавших файлах
serve --host 0.0.0.0  слушать все интерфейсы
serve --port 8080     порт
serve --page-size 50  книг на страницу OPDS
serve --public-url URL  внешний адрес для ссылок в OPDS
serve --scan          просканировать --library перед запуском
```

Примеры:

```bat
python -m kvhomelibrary scan "D:\Books" --db data\library.db --prune
python -m kvhomelibrary stats --db data\library.db
python -m kvhomelibrary serve --db data\library.db --host 0.0.0.0 --port 8080
```

## Импорт из архивов

В администрировании есть форма **«Импорт из архивов»**. Укажите каталог,
диапазон даты создания архивов и типы файлов:

- FB2;
- PDF;
- DjVu;
- EPUB.

Поддерживаются ZIP, 7Z и RAR. Для 7Z/RAR нужен установленный **7-Zip**
(`7z`) или `unrar`:

```bash
sudo apt install p7zip-full unrar
```

Windows: установите [7-Zip](https://www.7-zip.org/).

Найденные книги добавляются в каталог или обновляют существующие записи.
Каждый файл сохраняется в ZIP в `<library>/imported/<sha256>.zip`, поэтому
библиотека остаётся компактной. FB2 и EPUB открываются встроенными
читалками, PDF и DjVu можно скачать.

## Встроенная читалка

В карточке книги есть кнопка **«Читать»**, она открывает `/read/{id}`.

Режимы:

- **Прокрутка** — обычный вертикальный текст;
- **1 стр.** — одна страница на экран с листанием;
- **2 стр.** — две страницы на широком экране; на узком автоматически
  включается одна страница.

Страницы раскладываются CSS-колонками. Доступны:

- оглавление;
- размер шрифта и межстрочный интервал;
- светлая, сепия и тёмная темы;
- листание стрелками, `PageUp`/`PageDown`, пробелом и свайпами;
- сохранение позиции чтения в `localStorage` браузера;
- переход на весь экран.

### Читалка EPUB

Для EPUB используется [epub.js](https://github.com/futurepress/epub.js)
(версия 0.3.93, лицензия BSD-2-Clause; см.
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)). Библиотека включена в
`static/epub.min.js`, JSZip — в `static/jszip.min.js`; интернет для чтения
не требуется.

Доступны:

- режимы «Страницы» и «Прокрутка»;
- оглавление EPUB;
- размер шрифта и темы;
- сохранение позиции по CFI;
- листание кнопками, стрелками и `PageUp`/`PageDown`;
- полноэкранный режим.

EPUB отдаётся по маршруту `/book-file/{id}` и читается прямо в браузере.

## Подключение OPDS-читалки

1. Запустите сервер.
2. В читалке выберите «Добавить OPDS-каталог».
3. Укажите `http://127.0.0.1:8080/opds` (или IP компьютера в локальной сети,
   например `http://192.168.1.101:8080/opds`).
4. В корне каталога будут разделы «Авторы», «Категории», «Серии»,
   «Все книги».

Если сервер доступен извне, укажите `--public-url`, чтобы ссылки в фидах
формировались с правильным адресом:

```bat
python -m kvhomelibrary serve --host 0.0.0.0 --public-url http://192.168.1.101:8080
```

## Что извлекается из FB2

| Поле | Источник FB2 |
| --- | --- |
| Название | `title-info/book-title` |
| Авторы | `title-info/author` (имя, отчество, фамилия, псевдоним, e-mail, сайт) |
| Аннотация | `title-info/annotation` |
| Жанры | `title-info/genre` |
| Серия, номер | `title-info/sequence` (затем `publish-info/sequence`) |
| Издательство, город, год, ISBN | `publish-info` |
| Язык, язык оригинала | `title-info/lang`, `src-lang` |
| Переводчики | `title-info/translator` |
| Ключевые слова | `title-info/keywords` |
| ID, версия, дата документа | `document-info` |
| Обложка | `title-info/coverpage` → `binary` |
| Хэш, размер, путь, mtime | файловая система |

Названия жанров переводятся на русский по справочнику в
`kvhomelibrary/genres.py`; неизвестный код показывается как есть.

## Структура проекта

```text
KVHomeLibrary/
├── kvhomelibrary/
│   ├── fb2.py          разбор FB2, кодировки, ZIP, обложки
│   ├── db.py           схема SQLite, импорт, выборки, FTS5
```

## Тесты

```bat
python -m unittest discover -s tests -v
```

Тесты проверяют разбор метаданных, кодировки, ZIP, дедупликацию, перенос
файлов, поиск, фильтры, пагинацию OPDS, отдачу книг и обложек, ответы
сервера и OpenSearch.

## Как это работает

1. `scan` находит файлы и считает SHA-256.
2. Если файл с таким хэшем уже есть и путь не изменился, книга пропускается.
3. Иначе FB2 разбирается, метаданные нормализуются, обложка сохраняется,
   запись добавляется или обновляется в SQLite.
4. `serve` открывает соединение SQLite на каждый HTTP-запрос (WAL позволяет
   параллельные чтения) и формирует Atom-фид с профилем OPDS.
5. Ссылка `rel="http://opds-spec.org/acquisition"` ведёт на `/download/{id}`,
   ссылки `rel="http://opds-spec.org/image"` — на обложку.

## Ограничения и заметки

- Сервер не имеет аутентификации. По умолчанию он слушает `127.0.0.1`;
  публикуйте его в локальной сети осознанно.
- Полный текст книги в базу не сохраняется — только метаданные и обложка;
  скачивание отдаёт исходный файл.
- Дубликаты определяются по содержимому файла (SHA-256), а не по названию.
- Для очень больших библиотек первичное сканирование может занять время;
  повторные проходы пропускают неизменённые файлы.
- FTS5 входит в стандартные сборки Python для Windows; если его нет,
  поиск автоматически использует `LIKE`.
